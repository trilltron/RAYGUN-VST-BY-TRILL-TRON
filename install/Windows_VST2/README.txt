RAYGUN by TRILL TRON  v1.0.0  -  VST2 version (64-bit)  -  for FL Studio 20.0 - 20.6 and other older hosts
==========================================================================================================

1. Unzip this folder.
2. Right-click  Install_RAYGUN_VST2.bat  ->  Run as administrator.
3. FL Studio:  Options > Manage plugins > "Find installed plugins" (Start scan).
4. Channel rack > + > RAYGUN.

REQUIREMENTS
  * Windows 10/11, 64-bit.  * 64-bit FL Studio (FL 20 is 64-bit by default).  * Nothing else - no extra runtimes.

MANUAL INSTALL
  Copy RAYGUN.dll to  C:\Program Files\VSTPlugins\  (or into FL's  ...\Image-Line\FL Studio 20\Plugins\VST\ )

NOTES
  * Keyboard-safe: RAYGUN never takes your typing keyboard. Only the preset search box accepts typing.
  * Presets: click the preset name (top-left). Your own presets: menu > Save preset
    (stored in Documents\Trill Tron\RAYGUN\User Presets).
  * Quality (top bar): ECO / CLEAN / HOT. ECO is lightest on CPU.
  * Uninstall: Uninstall_RAYGUN_VST2.bat (as administrator).
